Veko Browser is a privacy-focused web browser for Android 8.0+ designed to stand between you, intrusive ads, and cross-site trackers—combining one-handed bottom navigation, strict memory discipline, and local-only data storage without analytics or ad SDKs.

Key features:
• 3-Ring Privacy Shield: Native Rust engine (brave/adblock-rust 0.13.4 via 16 KB ELF-aligned C++20 JNI), built-in subresource & cosmetic element-hiding WebExtension, and Mozilla GeckoView 150.0 Strict Enhanced Tracking Protection (ETP) + Dynamic First-Party Isolation (dFPI) + Global Privacy Control (GPC).
• Customizable Protection: Per-site Shield toggle, 5 toggleable filter packs (Core Ads, Anti-Tracking & Fingerprinting, Vietnamese Ad Shield, URL Tracking-Param Stripper for 44+ tokens, and Annoyance/Cookie Notices), plus automatic cookie-banner rejection.
• Practical Privacy Controls: Optional Clear-on-Exit data shredder, one-tap browsing trace shredder, media autoplay blocking, and portable HTML/JSON bookmark import & export.
• Multi-Language Interface: Built-in support for English, Vietnamese, Japanese, Korean, Simplified Chinese, French, German, and Spanish.
• Memory & Tab Discipline: Bottom-anchored address bar, one-handed gestures, hard 6-live-session LRU cap (MAX_LIVE_SESSIONS = 6), and RAM-only Private Browsing tabs protected with FLAG_SECURE.

Architecture: Powered exclusively by Mozilla GeckoView 150.0 (Gecko WebRender + SpiderMonkey) — never Android System WebView.
