Veko Browser는 침입형 광고와 교차 사이트 추적기로부터 사용자를 보호하는 Android 8.0+용 개인정보 중심 웹 브라우저입니다. 분석 및 광고 SDK 없이 로컬 전용 데이터 저장과 한 손 조작 하단 주소창을 제공합니다.

주요 기능:
• 3중 프라이버시 실드: 네이티브 Rust 엔진 (brave/adblock-rust 0.13.4 + C++20 JNI), 하위 리소스 차단 및 광고 요소 숨김 WebExtension, Mozilla GeckoView 150.0 엄격한 추적 방지 (ETP) + dFPI + GPC.
• 맞춤형 보호 제어: 사이트별 실드 스위치, 5개 필터 팩, 44개 이상의 URL 추적 매개변수 제거, 쿠키 배너 자동 거부.
• 실용적인 보안 도구: 종료 시 데이터 자동 파기, 미디어 자동 재생 차단, HTML/JSON 북마크 가져오기/내보내기, 8개 언어 지원.
